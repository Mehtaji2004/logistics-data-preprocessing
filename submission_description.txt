This report documents a complete data collection, cleaning and preprocessing pipeline for logistics analysis, built in Python with pandas, NumPy and Matplotlib, modeled after the publicly available DataCo Smart Supply Chain Dataset benchmark. I simulated an enterprise multimodal shipment dataset of 1,035 records across eight Indian hubs and four transport modes (road, rail, air and sea), with injected real-world quality problems: 338 missing values across six columns, 35 duplicate rows, inconsistent labels such as DELHI and 'delhi ', 6 negative distances, and extreme sensor outliers such as a 976.9-hour road trip over 1,094.6 km. The report walks through each preprocessing step with Python code snippets, mathematical foundations, and domain explanations: deduplication, label standardization (origin values consolidated from 16 to 8), domain invalid conversion to NaN, outlier detection using the robust IQR rule, missing value imputation (median for skewed numerics, mode for categorical), and dual-method feature scaling (Min-Max [0, 1] and Z-score standardization). A worked example illustrates shipment SHP100950 (2,017.6 kg) transformed to 0.6362 by Min-Max and 1.2358 by Z-Score. Quantitative before-vs-after results confirm a 52% reduction in distorted mean transit time (from 44.27 to 21.23 hours) and a 39.5% reduction in distorted shipping cost (from Rs 2,104.71 to Rs 1,272.27), leaving zero missing values. The reflection details how uncleaned data inflates working-capital safety stocks and freight budget forecasts, and discusses production considerations. The repository includes modular PEP-8 scripts, automated unit tests (test_pipeline.py), and full audit metrics in results.json.
